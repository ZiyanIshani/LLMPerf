# V1 Changes

## Files created

- `src/stats.py` — pure aggregation/statistics functions (`mean`,
  `percentile`, `aggregate_level`). Kept separate from `load_generator.py`
  because it's the piece with subtle-bug risk (percentile on an empty/
  all-null list, nulls-as-zero) and is cheap to unit test with no live
  endpoint involved.
- `tests/test_stats.py` — unit tests for `stats.py`: basic mean/percentile,
  empty-input, single-value, a mixed-null-and-real-data case (proving a
  failed request's null `ttft`/`generation_time` is excluded rather than
  counted as 0), and an all-errored level.
- `tests/test_load_generator.py` — unit tests for `send_request` using a
  fake streaming client (no live endpoint): normal success, a mid-stream
  failure, and a timeout. Added because implementing the timeout surfaced a
  real bug (see below) that the stats tests alone wouldn't have caught.
- `conftest.py` (repo root) — adds `src/` to `sys.path` so the test suite
  can `import stats` / `import load_generator` without installing the
  package first.
- `pyproject.toml` — pinned dependencies (`click==8.4.2`, `openai==2.45.0`;
  `pytest==9.1.1` under `[dev]`), packaged as flat top-level modules under
  `src/` (no console entry point — that's still explicitly out of scope).
- `README.md` — didn't exist before this pass; written fresh per the spec's
  status-section framing (there was no prior README draft in the repo or
  git history to update).

## Files changed

- `src/cli.py` — added `--request-timeout`, `--warmup-requests`,
  `--prompt-file`, and `--verbose` options; wired warm-up into
  `run_benchmark` before the timed sweep; replaced the `click.echo` status
  lines with `logging` calls configured by `--verbose`; added
  `build_prompts()` to produce either the existing generated filler prompt
  or a sampled pool from `--prompt-file`, recording prompt metadata
  (source, count, preview, approx word count) into the output JSON; changed
  the output JSON shape from a flat `{level: [requests]}` to
  `{"config": {...}, "levels": {level: {"requests": [...], "stats": {...}}}}`
  so the aggregation and run config are reproducible from the file alone.
- `src/load_generator.py` — added a hard per-request timeout via
  `asyncio.wait_for` wrapping the full request+stream-consumption (so a
  hung request can't stall a concurrency level indefinitely); added
  `run_warmup()`; `run_concurrency_level` now tracks wall-clock time for
  the level and calls `aggregate_level()` to attach a stats summary next to
  the raw request list; `send_request` and `run_concurrency_level` now take
  a list of prompts and sample one per request (`random.choice`) instead of
  a single fixed prompt, to support `--prompt-file`; replaced `print()`
  with `logging`; removed the stale `main()` / `__main__` dev harness at
  the bottom of the file (hardcoded `api_key="ollama"`, and its call
  signature no longer matched the updated functions — the real CLI is now
  the only entry point).
  - **Bug found and fixed while adding the timeout**: a request that failed
    partway through (mid-stream timeout, or any exception after some tokens
    had already arrived) was left with a non-null `ttft`/partial
    `token_times` alongside its `error`. That partial data would have
    quietly polluted `ttft_sec`/`generation_time_sec`/inter-token-latency
    stats with numbers from incomplete generations. Fixed by nulling
    `first_token_time`/`token_times`/`output_tokens` whenever `req.error`
    is set, so every failed request — timeout or otherwise — reports fully
    null metrics, matching the spec's "captured in error, metrics null"
    requirement. Covered by `test_send_request_mid_stream_failure_nulls_metrics`
    and `test_send_request_timeout_nulls_metrics`.
- `src/request_result.py` — fixed the `ttft` property's type hint
  (`-> float` to `-> float | None`); it already correctly returned `None`,
  the annotation just lied about it. No behavior change.
- `.gitignore` — added `*.egg-info/`, `src/results/`, `.pytest_cache/` (all
  generated by this pass's work: editable install metadata, benchmark
  output, test cache).

## Summary

V1 scope items 1-4 are done as specified: aggregated per-level stats
(mean/p50/p95/p99 TTFT and generation time, aggregate tokens/sec computed
as total tokens over level wall-time, mean inter-token latency, error rate,
all correctly excluding nulls rather than zeroing them) computed alongside
the untouched raw per-request list; a warm-up phase that measurably fixed
the cold-start TTFT problem (confirmed against a real local Ollama
instance — see the README's sample output); and a per-request timeout that
degrades to an ordinary captured error rather than a special path or a
stalled sweep.

Item 3 (prompt sizing) turned out to already be partially done — P0 had
already wired `--input-tokens` into a `build_prompt()` filler-word
generator, contrary to this spec's "currently unused" framing. What was
actually missing was recording the prompt in the output JSON, and that's
now done, plus `--prompt-file` was added as the (b) alternative for real
prompt content, since it was cheap to add given the existing single-prompt
plumbing needed to change anyway for multi-prompt sampling.

Item 5's first half (`--api-key` / env var) was also already done in P0;
only the hardcoded `"ollama"` default in `load_generator.py`'s dev-only
`main()` remained, which was removed along with that whole harness. The
second half — sampling across multiple prompts — is implemented via
`--prompt-file` plus `random.choice` per request.

Item 6 (hardening) is done: `pyproject.toml` with pinned deps, unit tests
for the aggregation logic (including the empty/all-null cases called out
in the spec as the likely bug source) plus tests for the per-request
error/timeout path that caught a real bug during this pass, and `print()`
replaced with `logging` behind `--verbose`. Deliberately deferred: a
mock-server integration test for the full sweep — the spec marks this
"good to have if time allows, not required," and the real-endpoint smoke
runs done during this pass (against local Ollama) covered that same
end-to-end path well enough to be confident without writing one.

Nothing else was deliberately deferred from this pass's scope.
